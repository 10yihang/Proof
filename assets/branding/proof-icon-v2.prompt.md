## Generation prompt

Use case: logo-brand
Asset type: A finished macOS application icon for Proof, a professional Git GUI focused on inspecting code changes and human review. Deliver exactly one icon, not a presentation board or a desktop mockup.
Primary request: Design a new, distinctive and beautifully crafted Proof app icon. Use a bold, custom white P monogram whose single rounded return stroke subtly resembles a Git branch joining its main stem. Make one coherent, memorable glyph with a clear open counter and balanced negative space, not several symbols pasted together. The silhouette must remain clear at 32 px.
Scene/backdrop: Square canvas with a genuinely transparent background outside the icon tile. Center a macOS-style continuous-corner rounded square tile, occupying about 88 percent of the canvas, with equal margins.
Style/medium: Precise, vector-friendly geometry with restrained dimensional finishing appropriate for a premium native developer tool. Front-on orthographic view, no tilt. A very subtle bevel and soft highlight give the tile depth; the white mark has only slight raised relief. Crisp edges, generous breathing room, professional and understated.
Color palette: Build on Proof's existing cobalt-blue and white identity. A rich cobalt / deeper sapphire tile with a gentle tonal light falloff, and a luminous solid white monogram. Strong contrast.
Composition: One large centered monogram, visually balanced within the tile. Broad consistent strokes, softly squared corners and smooth branching curves. Keep details simple enough for the Dock and small app-switcher sizes.
Text: No wordmark, no 'Proof' caption, no slogans; the single custom P is the icon.
Constraints: Original design. No code brackets, no generic checkbox, no shield, no sparkles, no robot, no busy circuit pattern, no rainbow gradients, no glass blur, no outer background rectangle, no cast shadow extending far outside the tile, no watermark. Preserve a real alpha channel outside the rounded-square silhouette.

## Refinement prompt

Use case: precise-object-edit
Asset type: Production macOS app icon, transparent PNG.
Input image: edit target, the newly designed blue Proof P / Git-branch app icon.
Primary request: Clean only the outer silhouette and its immediate rim. Remove every detached cyan or blue fleck, ragged pixel, halo and edge protrusion outside the rounded-square tile. The tile must have an immaculate mathematically smooth continuous-corner rounded-square contour with clean antialiasing.
Constraints: Preserve the P monogram, the embedded branch motif, their exact proportions and placement, the blue and white colors, tile size, equal transparent margins, the interior shading and overall composition. Do not redesign the glyph. Do not add text. Eliminate any exterior glow or cast shadow; every pixel outside the precise antialiased tile boundary must be fully transparent. Deliver one square image with real alpha, no background, no presentation or mockup.
