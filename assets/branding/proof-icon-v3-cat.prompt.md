# Proof icon v3 — Cat

New cute icon proposal: a warm cream cat holding a Git card, with a soft clay finish.

## Final generation prompt

Use case: logo-brand
Asset type: One new macOS app icon for Proof, a friendly Git GUI for reviewing code changes.
Primary request: A genuinely cute, charming app icon with no P monogram. Make a small rounded cat mascot hugging one simple code-review card. The cat has a big soft round head, tiny rounded ears, short paws, a small relaxed smile, and curious dot eyes. Its paws gently hold the card; the card carries only a tiny, clear Git branch motif consisting of two connected round nodes. Capture the feeling of a little companion helping someone look after their code.
Style/medium: A polished, softly dimensional illustrated app icon, like a carefully sculpted small clay character. Friendly and playful with a strong simple silhouette, not corporate or severe. Smooth clean surfaces, subtle soft lighting, no fuzzy textures or intricate details.
Composition: Exactly one centered app icon on a square canvas. A macOS continuous-corner rounded-square tile with balanced margins. The cat fills most of the tile, and its face must remain recognizable at small Dock sizes. One mascot, one card, nothing else.
Color palette: A soft blue tile related to Proof's existing blue identity, a warm cream-colored cat, a small peach accent on its cheeks and inner ears, and a pale code card. Clear separation between the character and background without harsh outlines.
Background: Genuinely transparent outside the rounded-square icon tile. Smooth clean silhouette and antialiased edges; no outer glow, stray particles or exterior cast shadow.
Text: No lettering, no P, no wordmark, no caption.
Avoid: shield, generic checkbox logo, briefcase, robot, mechanical mascot, stern expression, business look, excessive gloss, complex Git graph, tiny code text, additional objects, decorative sparkles, presentation board, desktop mockup, watermark.
