# Proof icon — friendly review window v1

Mode: built-in image_gen, no CLI fallback.

Asset: proof-icon-friendly-window-v1.png. Original generated PNG and alpha are preserved.

A new icon proposal: a friendly non-animal review-window character, with no letter monogram.

## Final prompt

Use case: logo-brand
Asset type: A new macOS application icon for Proof, a friendly Git GUI for reviewing code changes.
Primary request: Create exactly one original, charming icon with personality. The user wants something cuter and less serious, with no P monogram and absolutely no cats or other animals.
Subject: A tiny friendly anthropomorphic code-review window. A softly rounded, slightly plump little window with two simple dark eyes and a tiny relaxed smile. Its code area contains just a couple of short rounded horizontal diff marks, one gentle green addition and one muted coral deletion, arranged clearly apart from the face. The window itself is the character; no separate mascot, no arms or legs, no animal features.
Style: Tasteful playful macOS icon design, beautifully crafted soft ceramic / matte enamel, subtle rounded volume and clean shading. Expressive but quiet, cute without looking like a toy for toddlers. Very simple, bold shapes that read at small Dock sizes. Slight asymmetry gives the little window a curious, attentive expression.
Composition: One centered cream-white miniature review window with a soft cobalt-blue frame, comfortably filling a continuous-corner blue rounded-square app tile. Straight-on view, balanced proportions, generous breathing room. The face and diff marks are the only interior details.
Palette: Build on Proof's existing blue and white identity, softened for a warmer friendlier feeling. Green and coral only as tiny diff accents.
Background: Square PNG, genuinely transparent outside the rounded-square icon tile, crisp smooth clean silhouette and equal margins. No exterior glow, floating particles or cast shadow outside the tile.
Constraints: No letters or wordmark, no P, no animals, no ears, paws or tails, no human figure, no robot antenna, no code brackets, no shield, no checkmark badge, no sparkles, no text, no watermark, no presentation board, no desktop mockup. This should feel like a lovable little review window, not a formal enterprise logo.
