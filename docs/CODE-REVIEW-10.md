## Standards

1. 删除前排队的偏好保存可以借用新数据版本，重建刚清空的设置。每个挂载组件现在捕获请求代次；原生在锁内校验数据版本。原队列反例只产生一次旧写，后续旧回调被拒绝。

5. 不同窗口共享的 localStorage 标记可以被旧清理响应回退，误删 peer 的新草稿。不可变版本标记取最大值，草稿/文件视图按版本隔离，旧清理不能触及新版本内容。
6. 仅写前检查不足：peer 清理结束后，旧草稿仍可能迟到落盘。清理在枚举键前发布版本屏障，写入后再次核验；过期写入只撤销自己的旧 data epoch 槽，不删除 peer 的新槽。独立复核 9/9 通过，覆盖原红例、8 条存储交错和兼容性用例。
