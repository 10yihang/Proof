# Proof 界面改进

用户于 2026-09-12 要求重新打磨桌面界面、增加交互动画，并提供真正可用的 Git History Graph，随后提供炭灰三栏参考图，并要求参考 Fork / GitKraken。本轮将提交图提前纳入当前实现范围；原有 Git 写入、人工审查和 Agent 授权规则继续适用。

## 设计方向

Proof 是每天使用的代码审查工具。主要视觉是可追踪的提交线和清晰的代码变化，界面围绕它们组织，不堆叠统计卡片。左对齐、紧凑行高、固定信息列，当前选择与可操作区域有清楚层次。

- 浅色：纸白 `#ffffff`、工作区底色 `#f3f4f7`、墨色 `#222638`、次要文字 `#626b80`、蓝紫强调 `#535ce8`、辅助青色 `#158571`。
- 深色：炭灰底色 `#101317`、工作面 `#14181d`、控件层 `#20262f`、正文 `#e4e6ec`、次要文字 `#a0a7b4`、强调 `#a5a6fb`。比参考图提高次要文字对比度，减少右栏对代码宽度的占用。
- 字体：本机 SF Pro / PingFang 负责导航与正文，SF Mono / Menlo 负责代码和提交 ID；所有字体可离线工作。正文 13px，主要导航 13px，标题 17–20px，代码沿用用户字号。
- 动画：按钮反馈 100–140ms，选中态和面板 180–220ms，弹层进入 220ms、退出 140ms。动画响应用户动作；不在代码阅读区循环播放。尊重系统减少动态效果。

## 布局

```text
Proof  仓库 / 分支    Changes | History | Branches    刷新  观察状态  命令  设置
┌ 分支与工作区 ┬ 提交图 + 引用 + 说明 + 作者 + 日期 + ID ┐
│ 所有分支      │ ╭─●  feature/...   提交说明             │
│ 当前分支      │ ●─╯  main          合并提交             │
│ 本地 / 远程   ├ 所选提交 / 父提交 / 原始差异             │
└──────────────┴───────────────────────────────────────┘
```

Changes 延续文件树 / Diff / 可关闭 Context，宽窗把文件标题和工具条合为一行，窄窗自动折行并收起右栏。顶层只保留一层导航；底部显示真实路径与分支。Changes、History 和 Branches 切换时保留已加载的阅读视图。

History 提供虚拟化提交列表、彩色分叉/合并线、本地和远程引用、标签、作者时间、提交 ID 和下方详情。仅连接真实 parent OID；搜索突出匹配提交而保留拓扑，可在匹配结果之间跳转，也可使用方向键及 Home / End 浏览。合并提交可选择父提交，详情展示对应原始 Patch。

每次捕获冻结 tip OID、引用标签和本地历史形态。后续每页 100 条从同一组 tip 继续读取，引用移动不会把新旧历史混在同一张图里；显式刷新才重新解析具名分支。浅克隆边界明确标记，不把缺失父提交当空树比较。replace / graft 已启用时明确降级，捕获后历史形态变化则要求刷新；详情比较也受同一快照检查。远程引用仅代表本地已知状态。

演示模式的提交与 Context 会话均为虚构并标明“演示/示例”；真实模式不展示这些活动。参考图中的 Fetch、Pull Requests、Agent 数量并未作为已实现功能呈现。
