# Diff 阅读模型与显示边界

2026-09-13，基线 `be9b970`。本轮推进 DIFF-02/03/05/06、REV-01/05 和第 5 章阅读要求。Git 暂存、丢弃、Review 身份继续使用原始 Patch 与 Hunk；显示处理不生成可执行 Patch。

## 上下文扩展

提供 3 / 10 / 25 / 100 行选项。`diff_context(snapshotId, contextLines)` 校验原快照的文件、索引、基准和 Patch 后读取更宽的 Git 上下文，读取后再次校验。完整 index header 与原审查单元逐行匹配约束比较基准，只有未变化行和 EOF 提示进入额外间隔。

即使更宽的 Git Hunk 覆盖两个原单元，UI 仍保留两个独立审查/暂存单元，间隔只显示一次。已捕获的上下文可在外部修改后继续阅读；未捕获范围遇到变化时拒绝加载，不替换当前 Diff。

结果最大 4 MiB；缓存最多 8 项、估算上限 8 MiB，随快照释放，不是永久历史存储。专用文件摘要不走文本扩展。目录身份和信任检查沿用核心路径。

## 空白与行内差异

- 隐藏空白只折叠成对替换行中的空格、Tab、CR 差异。新增/删除空行、EOF 换行差异、全角空格和没有空白差异的相同文本仍显示。这不是语义等价判断，空白在字符串或语法中也可能有意义。
- 保留真实增删计数、审查单元和折叠数量提示。有隐藏内容的 Hunk 与整个文件不能新增 Review；显示全部后可标记，已有标记仍可撤销。App 动作入口也校验隐藏范围。
- 暂存包含完整原始变化。原始 Patch 模式总是显示原文，提示明确区分该模式与结构化折叠；显示开关不改 Patch。
- 行内差异使用有上限的词元 LCS，仅返回文本区间。语法、搜索、空白装饰保留原 DOM 文字；可视空白使用 CSS，复制不带额外字符。
- 单行超过 10,000 字符、搜索命中超过 64 或装饰区间超过 128 时简化高亮；空白装饰最多 64 个。完整原文和行级搜索定位保留，相关行提供说明。这个上限不代替完整大文件预览/NFR 验收。

## 导航与偏好

搜索当前加载的 Diff 与展开上下文，支持前后匹配行与 Enter / Shift+Enter，中文组合态不触发跳转。raw 模式关闭结构化搜索，避免误报匹配数。完整源码搜索仍待补充。

显示模式切换保存源行锚点；刷新时锚点携带所属快照 ID，重复文本或丢失位置明确说明并回到开头。同快照、同布局的隐藏/返回保留完整 scrollTop 和换行行内偏移，布局变化按源行与实际行高恢复；显式滚动或导航取消旧恢复任务。正行高缓存最多 10,000 项，随快照切换清理，零尺寸测量不覆盖已知值。

并排标签在垂直滚动容器外，左右栏各有横向滚动条、方向键和横向滚轮，行号/Hunk 操作固定。宽度来自实际字体度量；字号、装饰和上下文变化使缓存失效，不可见时暂停测量与偏移覆盖。

偏好加载后按请求顺序合并 partial 保存。初始读取不等待最近项目，待修改项覆盖初始值供 UI 使用；加载前不把默认 Git 路径写回存储。失败后从最近成功值继续，旧失败/迟到初始化不覆盖新操作。新增字段用 `serde(default)` 兼容已有设置。
