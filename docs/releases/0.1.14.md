# Proof 0.1.14

- **审查和提交范围更清楚**：分别显示已加载文件版本、已审查 Hunk 和未加载范围，提供“下一未审查文件”。Commit 默认查看已暂存版本；阅读未暂存候选时明确说明其不在本次提交范围内，并提供返回已暂存范围的入口。
- **阅读工具与证据更集中**：全文、上下文、历史、外部编辑器与原始 Patch 归入具名菜单，Hunk 审查按钮增加可见文字。证据面板先展示当前快照与验证边界，活动按需展开，支持关联已有会话。
- **交互、动画与无障碍改进**：Changes 与 Commit 分别保存阅读位置，经过 History 返回仍恢复原文件与代码行。统一减少动态效果策略，保留轻量指针反馈和即时键盘响应，修正代码字号滑块名称及设置等待状态的焦点恢复。改善 1024×720 最小窗口与中英文文案。
- **减少重复工作**：低频页面按需加载，主 JS 体积约减少 12%。隐藏窗口或非活动面板暂停 Context 轮询；Context 查询批量聚合，Comparison 复用固定快照文件清单，History 复用有界分页块。Observer 的启动和 heartbeat 等待移出 Core 锁，文件监听批量核对 Git ignore，并保留 Git 元数据与异常情况的保守刷新。
- **数据格式升级至 schema 8**：新增派生事件路径索引，支持事务回填与持续维护。安装包包含匹配的 Core 与 Observer；升级后的数据库无法由旧 schema-7 程序打开。

同一 Debug 夹具下，Context 查询中位耗时减少约 24%–33%，100 文件比较准备减少约 65%，深 History 分页减少约 38%。这些测量包含跟踪开销，不代表发布包的端到端点击延迟。前端 118 项、Rust 354 项测试通过，Edge 分批通过 147 个不同 UI 场景；原生 WebView 的完整点击链路 p95 与 CPU/RSS 尚未测量。

适用于 macOS Apple Silicon。0.1.1–0.1.13 可通过「设置 → 软件更新」升级；0.1.0 需手动下载安装包。

沿用现有 updater 签名密钥。macOS 包使用 ad-hoc 签名，尚未进行 Apple Developer ID 签名与公证。
