# Proof 0.1.9

- **新增嵌入式终端**：Changes 页底部可直接打开终端抽屉（顶栏按钮或 Ctrl+`），在仓库目录下启动登录 Shell，随开随用。终端按需加载——不打开不占用内存；滚动缓冲封顶 2000 行，输出经字节通道直推，长跑任务输出也流畅。进程退出后提示并可一键重启；Esc 或再次 Ctrl+` 收起，会话保留不中断。
- **移除底部操作栏，纵向空间还给 Diff**：原底部 54px 状态/操作栏整条移除。Review 进度（X/Y hunk）移到文件面板头部搜索框旁；终端 / 文件栏 / Context 三个面板开关移到顶栏右侧；「Stage / Unstage 整个文件」「丢弃文件」移到 Diff 视图工具栏（历史对比等只读视图不出现）；丢弃恢复点收进命令面板（⌘K）；专注审查按钮改为切换钮，再次点击即退出。
- 快捷键不变：⌘P 文件搜索、⌘K 命令面板、⌘⇧R 专注审查、Ctrl+` 终端。

适用于 macOS Apple Silicon。0.1.1–0.1.8 可通过「设置 → 软件更新」升级；0.1.0 需手动下载安装包。

沿用现有 updater 签名密钥。macOS 包使用 ad-hoc 签名,尚未进行 Apple Developer ID 签名与公证。
