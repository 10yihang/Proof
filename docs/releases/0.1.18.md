# Proof 0.1.18

- **OpenCodeReview 审查**。在本地变更和历史比较中通过 OCR CLI 发起审查。运行中可以查看进度，切换页面或关闭比较标签后，仍可通过顶栏入口查看审查状态和结果。
- **OCR 设置**。在设置中测试模型连接，查看内置规则，编辑全局规则和仓库规则。ChatGPT OAuth 网络失败或超时会显示对应原因。
- **仓库总览与切页**。从总览继续查看变更和审查。点击标签或使用快捷键切换页面时，主内容区沿导航方向滑入。系统开启「减少动态效果」时直接切换。
- **Diff 阅读**。保留首次读取未缓存文件时的内容和工具栏。新内容就绪后切换到目标文件，读取期间显示目标文件名。

适用于 macOS Apple Silicon。0.1.1 及之后版本可在「设置 → 软件更新」检查更新。0.1.0 需手动下载安装包。

应用沿用现有 updater 签名密钥。macOS 安装包使用 ad-hoc 签名。
