# Proof 0.1.1

- 检测本机 Codewiz 后，在 AI Agent 设置、Grouping 和 Review 中显示 Codewiz。读取 `~/.config/codewiz` 的模型配置与现有登录，不要求配置 API Key。
- Codewiz 使用独立的只读分析进程和临时运行目录，关闭 MCP、插件和自定义指令。不会续接或修改其他 CLI Session。
- 新增「设置 → 软件更新」：检查 GitHub Releases、下载进度、签名验证、安装并重启。Git 操作或 AI 分析正在运行时禁止安装。
- 软件更新不会自动下载或安装。0.1.0 尚未内置更新器，需要手动安装一次 0.1.1；后续版本可在应用内更新。

- Hook 上下文默认只展示当前文件相关活动，按原生 Turn 整理任务；重复读取与搜索折叠，修改、命令和失败输出直接可见。完整会话单独查看，未采集的历史详情明确提示。
- AI Grouping / Review 不再设置固定分析时限，保留手动取消、只读隔离与进度展示。
- 进入 History 或返回前台时自动 fetch，按仓库共享至少 1 分钟间隔；仅更新远程引用，后台执行且不弹窗。刷新提交图保留选中提交和滚动位置。
- Local Changes 在文件变化、切回页面或回到前台时静默刷新；监听不可用时自动改用定时刷新，更新当前 Diff 不再显示加载浮层或通知。
- 更新检查先核对 GitHub 最新正式版，再读取对应 tag 的签名更新清单，兼容没有更新清单的 0.1.0；区分网络问题、频率限制和尚未发布更新包。
