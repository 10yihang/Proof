# Proof 0.1.11

- **新增「文件」主标签页（⌘4）**：不离开 Proof 即可浏览仓库全部文件并直接编辑。左栏文件树默认折叠、单子文件夹链压缩显示，按类型着色图标并标注 Git 状态角标（M/A/U/D）；中栏是 Monaco 编辑器，支持语法高亮、⌘F 查找替换、代码折叠、缩进参考线、小地图与右键菜单；⌘S 保存走指纹乐观锁 + 原子写入，CRLF 文件按原行尾回写不产生噪声 diff，文件被外部修改时会提示重新加载或强制覆盖。
- **底部状态栏**：光标行列、选中字符数、语言、文件大小一目了然；点击 LF/CRLF 即可切换行尾；可选「自动保存」（编辑停顿后自动写盘，冲突时仍会先询问）。
- **文件历史栏**：右侧栏列出当前文件的提交历史（相对时间 + 最新标记），点击任意提交只读查看该版本全文，一键返回当前版本。
- **文件操作**：侧边栏可直接新建文件（支持 `a/b.txt` 一并创建目录）、行内重命名、删除——删除会先保存恢复点，7 天内可在「恢复点」中撤销，未跟踪文件也不会真正丢失。
- **终端全页面可用**：⌘` 与顶栏按钮在本地变更 / Commit / History / 文件任何页面都能呼出终端抽屉，不再限于本地变更页。

适用于 macOS Apple Silicon。0.1.1–0.1.10 可通过「设置 → 软件更新」升级；0.1.0 需手动下载安装包。

沿用现有 updater 签名密钥。macOS 包使用 ad-hoc 签名，尚未进行 Apple Developer ID 签名与公证。
