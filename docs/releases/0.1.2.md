# Proof 0.1.2

- 常驻 Git 工具栏：在 Local Changes、Commit 和 History 中直接使用 Fetch、Pull、Push、Branch、Stash 和恢复点。
- 分支下拉框与 History 共用操作菜单，支持 Copy Branch Name / Ref / SHA、Switch、Rename、Delete、Merge、Rebase；可以 Push 指定的本地 Branch，不必先切换分支。
- 文件树、文件列表和 AI Change Groups 增加文件操作菜单：Stage、Unstage、Discard、复制路径和文件名。历史 Diff 保持只读。
- 支持多选 / 文件夹范围 Discard，先保存恢复点并展示文件清单。untracked 普通文件也能 Discard 和恢复；并发修改会阻止过期操作，部分失败会明确报告。
- Stash 支持保存、Apply、Pop 和 Drop；可选包含 untracked 文件、恢复 Stage 状态。Pop 冲突时保留 Stash，Drop 需确认。
- 所有操作继续使用当前仓库的 Git、凭据和 Hook 配置，不依赖 AI 或 API Key。
