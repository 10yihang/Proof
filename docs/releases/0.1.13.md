# Proof 0.1.13

- **新增 OpenCodeReview Agent**：AI 面板的 Agent 列表新增第四个选项 OpenCodeReview（阿里开源的 `ocr` CLI）。在与其他 Agent 相同的只读沙箱中运行 `ocr review`——项目目录只读、CLI 身份校验、配置只读取不修改；审查过程实时可见（当前审查文件、轮次、工具调用），结果按严重级别映射进现有的 Review 面板，支持行级定位与 Accept/Dismiss。OCR 仅支持代码审查；智能分组和 Commit 信息请继续使用其他 Agent。模型与语言由 OCR 自身配置管理（`ocr config`）。
- **本地 AI 分析改为实时工作区**：本地改动的分组 / 审查 / Commit 起草不再冻结 diff 快照，Agent 直接对实时仓库运行 `git diff` 并阅读当前文件。准备阶段不再逐文件捕获 patch——100 个文件的准备工作从约 1.3s 降为接近 0（0 次 per-file Git 进程）；分析期间文件被修改不再触发 STALE_CONTENT 失败，报告照旧在内容过期后标记提示。历史对比审查不受影响（Commit 本身不可变，仍逐行校验引用行号）；Commit 信息落盘前仍会校验 Index 未变。
- **稳健性**：OCR 结果的各种终态（完成 / 跳过 / 部分完成）都能正确呈现；部分完成时保留已完成的发现并在摘要中标注覆盖范围；超长与多字节内容按字节安全截断，不再误杀整份报告。

适用于 macOS Apple Silicon。0.1.1–0.1.12 可通过「设置 → 软件更新」升级；0.1.0 需手动下载安装包。

沿用现有 updater 签名密钥。macOS 包使用 ad-hoc 签名，尚未进行 Apple Developer ID 签名与公证。
