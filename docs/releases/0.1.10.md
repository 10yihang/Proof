# Proof 0.1.10

- **文件树压缩单子文件夹链**：`src/main/java/com/xiaohongshu/...` 这类只有单一子文件夹的长路径（典型 Java 包结构）合并为一行显示，深层嵌套不再刷屏。
- **标签切换大幅提速**：进入 History 不再每次全量重走提交图——只在真正拉到新远程数据、手动执行 Git 操作或点刷新时才重载；本地通过终端提交/切分支由文件监听照常同步。同时移除了切换时反复重放的整页入场动画（掉帧来源），切换现在即点即显。
- **History 页头部合并为一行**：Git 操作（Fetch/Pull/Push/创建 Branch/Stash/恢复点）与当前分支、提交搜索、范围筛选同一行排布，头部高度减半；当前分支卡片改为紧凑按钮（点击定位 HEAD）。
- **标签页视觉清理**：激活标签去掉浮起卡片式的背景色块，只保留文字加粗与底部蓝色指示线；修掉了标签两侧 hover 照不到的暗缝和双指示线叠加的毛边。
- **Diff 顶栏防挤压**：面板宽度不足时文件名与工具栏自动分两行，工具栏按钮可换行，长文件名省略号截断（悬停显示完整路径），不再出现文字叠压按钮。
- **丢弃（Discard）支持图片等二进制文件**：已跟踪的二进制文件修改/删除可整文件丢弃并照常保存恢复点、随时撤销；Hunk 级丢弃保持文本限定。
- **Rebase 不再要求干净工作区**：自动携带 `--autostash`（未提交改动先暂存、变基后回放，untracked 文件不受影响）；`pull --rebase` 同样支持。Merge / Cherry-pick / Revert 保持原有要求。

适用于 macOS Apple Silicon。0.1.1–0.1.9 可通过「设置 → 软件更新」升级；0.1.0 需手动下载安装包。

沿用现有 updater 签名密钥。macOS 包使用 ad-hoc 签名,尚未进行 Apple Developer ID 签名与公证。
