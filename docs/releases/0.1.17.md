# Proof 0.1.17

- **文件切换不再闪空**：首次打开尚未加载的文件时，保留当前 Diff 和工具栏，目标内容就绪后一起切换；本地变更、历史 Diff、统一视图和并排视图均适用。
- **加载状态更清楚**：读取期间显示目标文件名，并暂停旧内容的暂存、Review 标记和外部编辑器操作。取消、快速切换和迟到响应不会覆盖当前选择。
- **保持阅读位置**：继续保留缓存切回、全文上下文、大文件回收及跨标签页的滚动恢复行为。

验证：136 项前端单测和 32 项相关浏览器回归通过；逐帧检查覆盖统一／并排视图的首次打开与缓存切回，未检测到代码区空白帧。该结果来自浏览器回归，不代表原生 WKWebView 帧率测量。

适用于 macOS Apple Silicon。0.1.1–0.1.16 可通过「设置 → 软件更新」升级；0.1.0 需手动下载安装包。

沿用现有 updater 签名密钥。macOS 包使用 ad-hoc 签名，尚未进行 Apple Developer ID 签名与公证。继续使用 schema 8 及配套 Observer。
