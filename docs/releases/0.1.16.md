# Proof 0.1.16

- **项目导航**：顶部显示居中的仓库名称与分支，下方项目标签可打开、切换和关闭仓库；Changes、Commit、History、文件与打开的 Diff 保留在左侧导航。
- **侧栏与窗口操作**：导航底部可收起／展开并记住选择；顶栏保留拖动空白。文件栏和上下文使用左右面板图标与准确提示，Fetch、Pull、Push、Stash 等操作保留在 History。
- **退出确认**：退出 Proof 或关闭主窗口前显示确认；取消保留窗口，独立 Diff 窗口关闭只影响自身。
- **仓库切换优化**：限量保留近期的小型阅读器，避免切换时反复创建编辑器和重读全文；保留草稿、阅读位置及返回时的磁盘变化检查。正式构建 Edge、真实 Git、两个 1200 行文件的 24 次预热切换，中位耗时由 246.6ms 降至 46.8ms；此结果不是原生 WKWebView 计时。

- **Finding 定位**：点击审查问题可对照当前 Worktree 与审查原位置；代码改写、删除或对应不唯一时显示待复核与限制，定位不会自动将问题标记为已解决。

适用于 macOS Apple Silicon。0.1.1–0.1.15 可通过「设置 → 软件更新」升级；0.1.0 需手动下载安装包。

沿用现有 updater 签名密钥。macOS 包使用 ad-hoc 签名，尚未进行 Apple Developer ID 签名与公证。继续使用 schema 8 及配套 Observer。
