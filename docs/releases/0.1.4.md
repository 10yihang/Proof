# Proof 0.1.4

- 文件树采用 32px 行高和 20px 层级缩进，默认宽度增至 320px，已有自定义宽度保留。文件状态放在名称前，长文件名可横向查看。
- 仓库、Branch、页面和 Diff tabs 合并为单行标题栏，保留 macOS 原生窗口控件和拖动区域。
- History 图中的 Branch 标签与同一 Commit 行右键共用 Git 菜单，明确显示 Branch / Commit 目标，并保留当前分支、所选分支比较和历史导航。
- 批量操作固定在文件树底栏，勾选、清除不再推动目录。普通点击查看 Diff，勾选、⌘/Ctrl 点击和 Shift 范围选择用于批量操作。
- Commit 左侧组合文件树与提交说明，右侧直接查看 Diff。与 Local changes 共用同一阅读器，切页保留当前文件、阅读状态和草稿。
- 修复窄窗口中当前 Diff tab 的关闭按钮被遮挡，以及勾选后移开鼠标时勾选状态不可见的问题。

适用于 macOS Apple Silicon。0.1.1–0.1.3 可通过「设置 → 软件更新」升级；0.1.0 需手动下载安装包。

沿用现有 updater 签名密钥。macOS 包使用 ad-hoc 签名，尚未进行 Apple Developer ID 签名与公证。
