# Proof 0.1.0

首个公开 macOS Apple Silicon 版本，采用新的简约分支图标。

## 主要功能

- Local changes 文件树、文件 / Hunk Stage，以及独立 Commit / Amend 页面。
- History graph、Branch 操作、Commit / Branch 比较、独立 Diff tabs 和窗口。
- 只读 Monaco Diff，支持统一 / 并排、上下文增减、全文、搜索和语法高亮。
- 使用本机 Codex CLI / Claude Code 进行 AI Change Grouping 和 AI Review；仅在主动点击后运行。
- Review 行范围评论、采纳 / 不采纳和本地持久化；选中意见可复制或导出为 Markdown，交给 Agent 修改。
- 中英文界面、可调整面板及独立的 Passive Agent Observer。

## 本次修复

- 修复 Git graph 连线错位和选中节点后连线被背景遮挡。
- 修复 Review 评论滚出视口再返回后消失，保留处理状态。
- 区分 Agent 分析受阻与成功但没有 Findings 的报告。
- 应用图标、欢迎页、设置页和原生包版本统一为 0.1.0。

## 下载与验证

在 [GitHub Release](https://github.com/10yihang/Proof/releases/tag/v0.1.0) 下载 macOS arm64 包。`SHA256SUMS` 提供下载文件的完整性校验，`release-manifest.json` 记录版本、源码 Commit、构建目标和验证范围。

当前构建采用 ad-hoc 签名，尚未进行 Apple Developer ID 签名与公证。该版本只提供 macOS Apple Silicon 包；其他平台与完整性能验收尚未完成。AI 功能使用已有 Coding Agent 的登录及额度；没有 CLI 时仍可使用普通 Git 和 Diff 功能。
