# Proof 0.1.15

- **界面文案精简**：移除文件树顶部的多行统计、Commit 中重复的范围说明及中央提示。文件数量保留在底部，详细统计按需查看，下一未审查文件改为紧凑图标入口。
- **修复 Commit 布局**：代码区恢复完整宽度，覆盖零暂存和混合暂存状态。切换 Staged 时清空文件搜索，并在需要时显示已暂存版本；提交、暂存和审查仍由用户明确触发。
- **修复上下文侧栏重叠**：会话标题和操作改为正常布局，历史与关联使用图标入口；空态仅保留简短状态与关联按钮，移除大虚线框和重复说明。保存关联后入口切换为图标时仍能正确恢复焦点。
- **窄窗口与中英文回归**：检查 1024×720 Commit 布局及 240px／300px 上下文侧栏，覆盖读取中、错误、空态、已有会话、解除后状态，并保留关联历史、草稿、原始证据和真实 Git／SQLite 校验。

适用于 macOS Apple Silicon。0.1.1–0.1.14 可通过「设置 → 软件更新」升级；0.1.0 需手动下载安装包。

沿用现有 updater 签名密钥。macOS 包使用 ad-hoc 签名，尚未进行 Apple Developer ID 签名与公证。本版本继续使用 schema 8 及配套 Observer；schema-7 程序无法打开已升级的数据。
