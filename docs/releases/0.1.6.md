# Proof 0.1.6

- History 的 Push 对话框新增 **Force Push with Lease**，默认仍为普通 Push。预览显示本地来源、远程目标和确认的远程 Commit，用户确认后执行。
- Force Push 使用固定 Commit 的显式 lease，只更新所选远程 Branch；远程出现后续变更或被并发创建时拒绝覆盖。支持独立的 Push URL，后台 Fetch 不会悄悄推进已确认的 lease。
- History 固定显示当前本地 Branch 和 HEAD。点击 **定位 HEAD** 可返回当前 Commit，并清除搜索和比较选择；若 HEAD 不在当前范围或已加载页面，会直接显示当前 Branch 历史。
- 图中和侧栏增加清晰的 HEAD 标签，当前本地 Branch 与远程引用分别展示。选中其他 Commit 后，HEAD 标记继续保留。
- 首次进入 History 时优先选中并显示已加载的 HEAD；后续刷新保留阅读位置和所选 Commit。Detached HEAD 显示 Commit ID，尚无 Commit 的 Branch 禁用定位。

适用于 macOS Apple Silicon。0.1.1–0.1.5 可通过「设置 → 软件更新」升级；0.1.0 需手动下载安装包。

沿用现有 updater 签名密钥。macOS 包使用 ad-hoc 签名，尚未进行 Apple Developer ID 签名与公证。
