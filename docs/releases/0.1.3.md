# Proof 0.1.3

- Fetch、Pull、Push、Create Branch、Stash 和恢复点统一回到 History 工具栏。
- AI Review / Change Grouping 直接只读访问原项目目录，可以按需查找完整文件、调用方、测试和配置。选定 Git Diff 仍作为审查范围与行号依据，历史比较使用固定 Commit；AI 不会修改文件或 Git 状态。
- Codewiz 新增 Passive Hook 设置，支持检测、安装预览、暂停与卸载。安装后重新打开 Codewiz 即可加载；现有 Session 保持不变。
- Agent 检测、主动分析和 Hook 设置共用能力目录，主动分析与被动观察的运行过程、授权和存储仍然独立。
- 修复 macOS 上 `/usr/bin/git` 转调 Xcode Git 时被分析沙箱拦截的问题，无需修改 Git 路径或 PATH。
- Agent 进度可显示正在读取的项目上下文文件；Codewiz 退出时短暂等待已发送的 Hook 事件，减少末尾记录丢失。

适用于 macOS Apple Silicon。已安装 0.1.1 / 0.1.2 的用户可在「设置 → 软件更新」中升级；0.1.0 需手动下载安装包。

沿用现有 updater 签名密钥。macOS 包使用 ad-hoc 签名，尚未进行 Apple Developer ID 签名与公证。
