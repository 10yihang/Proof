# Proof 0.1.5

- 新增 **AI Commit**：使用本机 Agent 为 Staged 变更生成可编辑的提交说明，支持 Amend。已有草稿和生成期间输入的内容会保留，由用户决定是否使用建议；不会自动 Stage、Commit 或更改 Review 状态。
- 在「设置 → AI Agent → 自定义 Prompt」中，分别配置 AI 分组、AI Review 和 AI Commit 的语言、风格与关注点。各项独立保存，也可单独恢复默认。
- 分组、Review 和 AI Commit 的新会话保留在对应 Agent 中，结果提供「在 CLI 中继续此会话」命令。每次任务独立启动，分析期间保持只读，不接管其他终端的会话。
- 修复 Codewiz 输出包含日志、ANSI 控制序列或换行差异时触发 `AI_INVALID_OUTPUT` 的问题；修复较长结果和原生会话导出被截断的问题，保留活动进度、取消和结构校验。
- 改善任务取消、切换 Amend、Git 内容变化时的结果处理，避免过期的 AI Commit 建议覆盖当前草稿。

Codex 的会话选择器可能需要 `--include-non-interactive`；Claude Code 的 print 会话可通过提供的 Session ID 恢复，不一定出现在默认选择器中。原生 CLI 自行管理这些会话，清除 Proof 数据不会删除它们。

适用于 macOS Apple Silicon。0.1.1–0.1.4 可通过「设置 → 软件更新」升级；0.1.0 需手动下载安装包。

沿用现有 updater 签名密钥。macOS 包使用 ad-hoc 签名，尚未进行 Apple Developer ID 签名与公证。
