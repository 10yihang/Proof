# Proof 0.1.12

- **Commit / History / 文件页卡片可拖拽调宽**：工作区改为卡片式布局，各面板宽度随手调整并自动记住，重启后保持。
- **AI 分组 / 审查 / AI Commit 的准备阶段提速约 85%**：批量复用仓库状态与文件 guard 的共享输入，不再逐文件重复读取 status/refs/索引/配置。100 个文件的准备耗时中位数从 9.1 秒降至 1.3 秒（Git 进程数减少约 90%），文件越多收益越大。
- **「文件」页后台不再空转**：切到其他标签或窗口隐藏时，暂停对当前文件的原生读取与文件列表刷新，回来后自动补齐——长时间挂着编辑器更省电省内存。
- **提交图增量布局**：加载更多历史时只在既有布局上追加新提交，不再整图重排；Fetch 现在能识别部分成功（个别远程失败但 refs 已移动）并照常刷新图。
- **终端会话生命周期修复**：切换/关闭工作区时，异步回调严格归属于发起它们的会话，杜绝串台与悬挂进程。

适用于 macOS Apple Silicon。0.1.1–0.1.11 可通过「设置 → 软件更新」升级；0.1.0 需手动下载安装包。

沿用现有 updater 签名密钥。macOS 包使用 ad-hoc 签名，尚未进行 Apple Developer ID 签名与公证。
