# Proof 0.1.8

- **History 分支侧栏改为嵌套文件夹树**：本地分支与远程引用按分隔符逐层折叠(如 `codex/backup/*` 收进 `codex ▸ backup`),远程引用统一归入 `origin` 树;单层堆叠的数十个分支不再挤满侧栏。
- **分支折叠支持动画与防抖动**:展开/折叠有 220ms 平滑过渡(尊重系统减少动态效果设置);侧栏预留滚动条位置,展开分组时内容不再横向跳动。
- **分支分组分隔符可配置**:「设置 → 外观与阅读」新增分隔符输入,默认 `/`,可改为 `-`、`.` 等以匹配你的分支命名习惯。
- **移除独立 Branches 页面**:其能力已被 History 侧栏完全覆盖(嵌套树、双击切换、右键操作),顶部导航精简为本地变更 / Commit / History,快捷键相应调整为 ⌘1–⌘3。

适用于 macOS Apple Silicon。0.1.1–0.1.7 可通过「设置 → 软件更新」升级;0.1.0 需手动下载安装包。

沿用现有 updater 签名密钥。macOS 包使用 ad-hoc 签名,尚未进行 Apple Developer ID 签名与公证。
