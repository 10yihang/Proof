# Proof 设计约定

开发者每天使用的本地审查工作台。1440×900 基准，1024×720 最小窗口。代码优先，默认左对齐；左侧 240px 文件导航，中央 Diff 占主要空间，右侧 300px 证据检查器可收起。

检索结果偏向文档落地页，与产品不匹配，因此以 PRD 为准，不采用其 Hero、FAQ、霓虹绿色方案。

- 页面白 #FFFFFF；侧栏浅灰 #F7F8FA；正文石墨 #242833；次要文字 #616976；操作蓝 #315BCE；分隔 #E3E6EB。
- 红绿专用于代码增删。Reviewed 使用蓝色勾选与文字；来源、验证各有独立标签。
- 深色使用中性灰表面 #191C22 / #20242C，独立校验对比度。
- 界面使用系统 UI 字体及中文系统回退；代码使用 SFMono-Regular / Menlo / Consolas。全部离线，不加载远程字体。
- 标志是代码括号中的审查笔画，使用本地 SVG；其余图标统一 Phosphor 线性。
- 文件树用轻量行，编辑器按需加载，主要动作有文字。无营销卡片、统计仪表盘、AI 对话主导航。
- 常驻文案保持简短，不重复筛选器、数量和按钮已表达的信息；范围明细与解释按需查看，不能挤占代码区域。
- 弹层负责明确范围与后果；错误保留输入并解释下一步。键盘、IME、200% 缩放与减少动态效果属于验收项。

## 功能交互的参考顺序

按用户明确要求，新增功能前先核对已有成熟产品的实际操作流程，记录入口、选择方式、结果展示位置及返回行为，再决定 Proof 的实现。不能只对照功能清单添加独立表单或页面。参考不覆盖用户自己的偏好：History 选择 Commit/Branch，Diff 结果在新 tab 展示，Commit 独立成页。

## 项目与视图导航

顶部使用项目标签，可打开、切换和关闭仓库；完整路径放在标签提示中，同名仓库依照实际 workspace identity 去重。左侧固定 Changes、Commit、History、文件四个入口，1024 宽度下收为带可访问名称的图标导航。分支切换与当前项目工具在上方工具栏，项目标签位于其下方；History 打开的 Diff 比较项在左侧 History 下方显示。

切换项目保留各项目的视图、草稿、编辑文本和阅读位置，隐藏项目暂停自动刷新与全局快捷键。关闭有未保存文件的项目须确认；正在保存、执行 Git 或 AI 任务的项目不能关闭。Ctrl+Tab / Ctrl+Shift+Tab 切换项目，⌘/Ctrl 1–4 切换当前项目视图。

布局参照 [Fork 官方界面](https://fork.dev/) 的顶部仓库标签与左侧导航，[官方更新记录](https://fork.dev/releasenotes) 中的项目快捷切换与逐项目状态保留。

## 默认信息密度

按 Fork 参考图将操作工具栏与项目标签分成两层：上方 48px 工具栏，左侧保留应用标志及拖动空白，中央显示项目名称及分支选择，右侧放阅读与应用工具；下方 32px 项目标签栏可快速切换和关闭项目。顶栏背景与两侧空白是窗口拖动区，交互控件不标记拖动。Fork 参考仅限仓库信息居中。Fetch、Pull、Push、Stash 等操作保留在 History，不作为全局顶栏入口。文件栏和上下文入口使用对应的左右面板图标，悬停提示解释其功能，不显示“证据”标签。

History 的 Diff 在侧栏列出，支持切换、关闭和纵向排序。比较范围、完整 OID、父提交、方向和独立窗口通过文件头的比较详情展开；文件栏、AI Review 和阅读工具保留直接入口。正常文件头约 44px；不压缩代码字体或行距。没有比较项时，侧栏宽 136px，有比较项时 160px。底部提供收起／展开入口，收为 48px 图标栏后仍可切换页面和 Diff，选择在项目间共享并保存。窄窗口优先保留图标入口与完整的可访问名称。

退出应用及关闭主窗口均需原生确认，取消保留窗口；独立 Diff 窗口关闭只影响自身。
