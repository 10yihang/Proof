# Proof 设计约定

开发者每天使用的本地审查工作台。1440×900 基准，1024×720 最小窗口。代码优先，默认左对齐；左侧 240px 文件导航，中央 Diff 占主要空间，右侧 300px 证据检查器可收起。

检索结果偏向文档落地页，与产品不匹配，因此以 PRD 为准，不采用其 Hero、FAQ、霓虹绿色方案。

- 页面白 #FFFFFF；侧栏浅灰 #F7F8FA；正文石墨 #242833；次要文字 #616976；操作蓝 #315BCE；分隔 #E3E6EB。
- 红绿专用于代码增删。Reviewed 使用蓝色勾选与文字；来源、验证各有独立标签。
- 深色使用中性灰表面 #191C22 / #20242C，独立校验对比度。
- 界面使用系统 UI 字体及中文系统回退；代码使用 SFMono-Regular / Menlo / Consolas。全部离线，不加载远程字体。
- 标志是代码括号中的审查笔画，使用本地 SVG；其余图标统一 Phosphor 线性。
- 文件树用轻量行，编辑器按需加载，主要动作有文字。无营销卡片、统计仪表盘、AI 对话主导航。
- 常驻文案保持简短，不重复筛选器、数量和按钮已表达的信息；范围明细与解释按需查看，不能挤占代码区域。
- 弹层负责明确范围与后果；错误保留输入并解释下一步。键盘、IME、200% 缩放与减少动态效果属于验收项。

## 功能交互的参考顺序

按用户明确要求，新增功能前先核对已有成熟产品的实际操作流程，记录入口、选择方式、结果展示位置及返回行为，再决定 Proof 的实现。不能只对照功能清单添加独立表单或页面。参考不覆盖用户自己的偏好：History 选择 Commit/Branch，Diff 结果在新 tab 展示，Commit 独立成页。

## 项目与视图导航

顶部使用项目标签，可打开、切换和关闭仓库；完整路径放在标签提示中，同名仓库依照实际 workspace identity 去重。左侧固定 Changes、Commit、History、文件四个入口，1024 宽度下收为带可访问名称的图标导航。分支切换与当前项目工具在上方工具栏，项目标签位于其下方；History 打开的 Diff 比较项在左侧 History 下方显示。

切换项目保留各项目的视图、草稿、编辑文本和阅读位置，隐藏项目暂停自动刷新与全局快捷键。关闭有未保存文件的项目须确认；正在保存、执行 Git 或 AI 任务的项目不能关闭。Ctrl+Tab / Ctrl+Shift+Tab 切换项目，⌘/Ctrl 1–4 切换当前项目视图。

布局参照 [Fork 官方界面](https://fork.dev/) 的顶部仓库标签与左侧导航，[官方更新记录](https://fork.dev/releasenotes) 中的项目快捷切换与逐项目状态保留。

## 默认信息密度

按 Fork 参考图将操作工具栏与项目标签分成两层：上方 48px 工具栏，左侧保留应用标志及拖动空白，中央显示项目名称及分支选择，右侧放阅读与应用工具；下方 32px 项目标签栏可快速切换和关闭项目。顶栏背景与两侧空白是窗口拖动区，交互控件不标记拖动。Fork 参考仅限仓库信息居中。Fetch、Pull、Push、Stash 等操作保留在 History，不作为全局顶栏入口。文件栏和上下文入口使用对应的左右面板图标，悬停提示解释其功能，不显示“证据”标签。

History 的 Diff 在侧栏列出，支持切换、关闭和纵向排序。比较范围、完整 OID、父提交、方向和独立窗口通过文件头的比较详情展开；文件栏、AI Review 和阅读工具保留直接入口。正常文件头约 44px；不压缩代码字体或行距。没有比较项时，侧栏宽 136px，有比较项时 160px。底部提供收起／展开入口，收为 48px 图标栏后仍可切换页面和 Diff，选择在项目间共享并保存。窄窗口优先保留图标入口与完整的可访问名称。

退出应用及关闭主窗口均需原生确认，取消保留窗口；独立 Diff 窗口关闭只影响自身。

## 原生 macOS 工作台（2026-11-02，Fork 布局 / Linear 视觉）

用户批准的完整概念稿取代此前 CodeEdit 风格和 B 顶栏方案。本节仅约束新增 SwiftUI 前端，上文 Web/Tauri 约定原样保留。概念方向认可不代表当前代码、像素或交互已验收；不将私人参考仓库内容写入源码或合成演示。

### 布局与行为

- 原生 `unifiedCompact` 工具栏承载一个真实活动仓库标签与打开动作，不再保留居中主标题、大块空灰栏或标题胶囊。标签显示当前仓库名和变化数量；打开其他仓库替换当前仓库，关闭/替换保护提交草稿。不宣称多仓库标签状态管理。
- 根 `NavigationSplitView` 左侧为仓库导航，最小168pt、理想208pt、最大240pt。提供真实的本地更改/提交历史入口与当前分支信息；分支信息不是切换控件。左右列局部 `GeometryReader` 限制实际视口，避免原生宿主的固有尺寸溢出。不用猜测标题栏 padding 或根 safe-area overlay。
- 右侧顶部42pt分支/刷新/上下文栏，下方为文件分区、灵活 Diff、底部检查提交区。文件列在 detail 视口宽度小于1000pt时为250pt，否则310pt；不把这一条件误写为整窗断点。
- 文件标题44pt，筛选框使用轻量5pt圆角。默认压缩目录树，已暂存/未暂存分区始终可见，路径搜索与目录折叠保留。文件行通常34pt、选中行46pt，选中快照有已知增删数字；分组34pt、目录28pt，List 最小行高32pt。软灰紫选择不等于人工评审，状态有文字/符号而非仅颜色。
- Diff 文件头50pt，包含文件名、路径、人工评审状态和整文件暂存/取消暂存。其下34pt比较行显示实际方向、增删计数和统一 Diff/原始补丁阅读菜单。代码13pt、22pt行高、105pt原生行号槽；保留原生选择、复制、查找与滚动，代码面为实底。
- 底部内联提交区保留54pt输入区域、已暂存文件数与“检查提交…”入口，随后仍须真实预览与明确确认。信任、草稿、busy/write、内容/索引/HEAD过期检查不因内联布局省略。仅创建本地提交，不隐式推送或 amend。
- 24pt底部状态栏显示真实状态或明确的合成演示提示。上下文入口使用300×470pt只读快照弹出面板，不常驻挤占 Diff。仅显示已知路径、比较范围、HEAD、快照ID、人工评审与信任；验证结果明确未报告。
- 应用自有 UI 与提示中文，文件名、代码、Git标识和后端错误保留原文。评审覆盖仅基于已加载快照，未加载项未知；下一待评审文件包含未知项。

### 能力边界与本轮验证

概念中的多仓库、fetch/pull/push、分支切换、stash、标签/远程树、分栏 Diff、hunk 暂存/跳转、amend 未在此原生版本实现，省略而非摆放假的可用控件。Files编辑器、完整History图/比较标签、AI/会话上下文和验证证据也不宣称已有。原有 Rust 后端不改。

本轮源码 `c6be5fadf7c8d19e7fb9ddcb7bb742da1354f865` 在 [CI 41432134236](https://github.com/10yihang/Proof/actions/runs/41432134236)（job 125233030388）通过：4项 Rust bridge 真实 Git 测试、Swift 文件树/状态/草稿与写入守卫检查、release 构建、签名/协议检查及四张真实窗口捕获。

初始代码滚动位置按布局后的原生 clip insets 修复，只在内容身份改变时定位；四张捕获均验证 `startsVisible=true`。审阅结果为 SHIP，限定于本轮视觉修正已解决，不代表用户审美接受、完整交互或辅助功能验收。
