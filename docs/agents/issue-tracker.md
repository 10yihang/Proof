评审与实现使用 PRD 的 REPO/DIFF/GIT/REV/OBS/CTX/EVD/SET/SEC/NFR 和 AT 编号。不得创建外部 Issue、发送消息或推送仓库来替代本地跟踪，除非用户另行授权。

当前第一次代码评审比较整个新增工程与空目录基线；尚无 HEAD 时使用 `git diff --cached --` 查看已暂存的完整新增内容，不虚构提交范围。
