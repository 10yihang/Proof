# 界面与提交图检查点

日期：2026-09-13；比较基线 `9fd7399`。本次包含用户指定的视觉改进、动效和 Git History Graph；分别执行 Standards 与 Spec 独立只读评审，反例在隔离源码/target 和独立组件浏览器中运行。

## Standards

1. 只读历史曾继承 `log.showSignature`，可能触发仓库指定的 `gpg.program`。图查询及相关历史元数据查询显式关闭签名展示；未信任仓库反例确认自定义程序没有执行。Git 写入的签名与 Hook 行为未改变。
2. 图快照存在时，提交详情曾读取实时父提交形态。新增 `graph_commit_diff`，用同一捕获范围及历史形态检查保护详情；捕获后 replace / graft / shallow 改变时明确拒绝。
3. 弹层退出动画曾留下 Escape 后立即 Enter 的提交窗口。关闭时同步设置关闭引用和 inert，阻止 submit 与按键，再播放退出动画；独立交互回归确认取消后不会提交，正常提交和减少动态效果仍可用。
4. 虚拟列表曾在选中行滚出可见区后留下无目标的 `aria-activedescendant`。现在额外保留选中行，独立 300 行测试中仅渲染 33 行，活动节点持续存在，隐藏恢复及 Home / End 有效。

以上发现已修复并独立复核，最后复核未发现对应直接回归。

## Spec

1. `--no-walk` 与 `--max-count` 组合曾使单分支长历史被误计为大量 tip。去掉 tip 捕获的遍历限制，真实 1100 条单分支回归通过。
2. 具名分支刷新曾继续使用旧 OID，历史中的祖先分支/标签也可能遗漏。刷新重新解析完整 ref 名；捕获时独立冻结引用标签，后续分页保留捕获状态。
3. 浅克隆曾把边界视作根提交并尝试空树对比。新增显式 shallow 边界并禁用缺失父版本的比较；已启用 replace / graft 的历史也明确降级。详情同步使用图快照检查。
4. 减少动态效果最初未覆盖 backdrop；现在覆盖所有相关伪元素。最后一项 P3 文案也已调整：仅存在未加载父线或浅边界时提示本地历史边界，其余显示“全部 N 条已加载”。

独立定向复核为 Rust 14/14、布局 4/4；末次只剩上述 P3 文案，随后主工作区完成修正。此结果针对本轮范围，不等于全部 PRD P0 验收。
