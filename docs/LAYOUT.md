# 仓库布局与可调整面板

2026-09-13；基线 `7dee898`。对应 PRD 5.3 / 5.4、SET-01，并推进 AT-29。

默认文件栏 240px、上下文 300px。分隔条支持拖动、左右方向键、Shift 加速、Home/End 边界、Enter 收起和双击恢复默认宽度；设置页提供直接输入和加减按钮。拖动期间只更新显示，松开后保存；取消手势不保存。

布局使用本地 repository ID 存储：同一仓库的 linked worktree 共用，独立 clone 分离。文件栏宽度 180–480px、上下文宽度 240–520px，核心校验数值和当前工作区身份。仓库级 Context 覆盖可以恢复为跟随应用默认，界面显示设置范围。恢复此仓库默认布局只写布局记录，不清理仓库、Review 或 Agent/Git 配置。

保存宽度和实际呈现宽度分开：空间不足时先缩上下文，再缩文件栏，为代码保留至少 360px；1100px 以下上下文用抽屉，780px 以下文件栏也用抽屉。临时缩窗不会把收缩后的宽度写回。很矮的窄视口允许页面纵向滚动，保留可阅读的代码区。Cmd/Ctrl+P 能展开文件搜索，选择文件后收起窄窗文件栏并把焦点交给 Diff；关闭抽屉返回触发按钮。

每个仓库有独立的布局保存队列。初始化读取完成前禁用持久化调整，避免用默认值覆盖已有配置；保存串行合并 partial，失败回滚到最近成功值并显示错误，晚到响应不更新另一仓库。已有排队写入成功不会清掉早先失败提示，下一次明确调整才清除旧提示。演示值只在当前前端进程保留，不调用原生存储。

失焦、隐藏、取消指针或退出当前可交互视图会同步清除拖动草稿，迟到的 pointerup 不再保存。非模态抽屉在焦点离开时收起并保留目标焦点，避免键盘落到被覆盖按钮；进入模态设置时暂时保留抽屉，使弹层关闭后能返回原按钮。

SQLite 新增 `repository_layouts`，schema 从 3 升到 4；旧数据原位兼容迁移，旧版 Proof 会按已有版本保护拒绝重新打开 schema 4。没有修改 Agent 或仓库配置。IPC 为 `repository_layout(workspaceId)` 和 `set_repository_layout(workspaceId, layout)`，不会产生 Git 操作或 Review 事件。

分隔条的语义和方向键依据 [WAI-ARIA Window Splitter 模式](https://www.w3.org/WAI/ARIA/apg/patterns/windowsplitter/)；这份模式自身仍标注示例/评审未完，不据此宣称完整无障碍标准达标。

尚需完成的相关范围包括：所有设置的应用/仓库覆盖、外部编辑器、完整选择持久化、完整键盘与 200% 缩放矩阵，以及完整 P0/NFR。定向回归和原生证据继续记录到 `ACCEPTANCE.md`。
