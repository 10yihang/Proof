# Agent 版本检测与配置规划检查点

日期：2026-09-12；比较基线 `ac27402`。范围为固定版本查询及设置入口、候选适配配置、保留原始 JSON 的所有权增删规划。两轴独立只读评审，反例在临时源码与独立 target 中运行；物理安装器和真实 Agent Hook 验收不在本次通过范围。

## Standards

1. 旧工作区信任曾在 `.git` 替换后继续允许版本程序执行。现在准备与执行阶段重新核对实际仓库身份和信任；旧审计记录失效，重新打开的新身份可单独授权。撤销信任的回归也通过。
2. 升级曾先删除旧 Hook，再校验用户改过的 matcher。现在先核对原定义，范围变化、重复和移动均返回冲突，不生成丢失用户限制的升级方案。
3. 目录符号链接曾因提前规范化而丢失未信任仓库来源。新增反例先证明程序被执行；修复后逐级保留链接来源，目录/末级/相对/链式链接统一核对，循环链接受 40 次展开上限约束。程序元数据身份也能拒绝准备后的文件替换。

3 项实质发现已修复并复核。最后定向独立复核为 10 条通过、1 条真实 CLI 查询跳过，未发现新的实质问题。版本查询已移出 Tauri Git mutex，并由原生 dispatch 回归核对慢程序运行时锁仍可取得；元数据检查不冒充二进制签名。

## Spec

1. 安装/重复安装/升级曾接受 matcher 变化、重复拥有条目或移动事件，升级时还会消除旧限制。安装前统一检查注册定义及所在范围；原先 4 条相关反例通过。
2. 卸载曾在 `hooks` 字段不存在时漏查其他可执行字段的注册引用。现在扫描残留引用，遇到被移动的条目报冲突，避免后续清理 helper 时留下失效命令。

2 类实质发现已修复并复核。独立配置测试为 16/16 通过，包括原先失败的 5 条反例；未知版本不被标为支持，所有权 schema 仍可移除历史版本的注册。OBS-01—05 的配置落盘、备份、并发保护、策略检测、完整安装与卸载以及真实事件验证仍未完成。

## 验证边界

浏览器演示已核对版本检测入口、禁用原因和未验证文案；浏览器不执行本机程序。桌面 dispatch 与核心查询是本地进程测试，不代替原生按钮交互。原生新增入口仍待可操作的 Mac 桌面复验。

默认并行全量运行中，两条桥接进程耗时断言超过 500 ms；随后串行全量仍有一条超限。独立串行的 8 条传输测试、同依赖组合下的定向复测和 30 组调试诊断未再次复现；原因尚未关闭。断言阈值保持不变，新增启动与总耗时信息。不能据单次通过宣称 NFR-06/09 或并行突发性能已完成。尚需发布构建下的启动/主入口耗时分解、持续吞吐和进程树资源测量。
